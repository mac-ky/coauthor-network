# 共著者ネットワーク検索（静的サイト版）

著者名を入力すると [Semantic Scholar](https://www.semanticscholar.org/) から論文情報を取得し、共著関係をインタラクティブな
ネットワーク図として可視化するWebアプリです。**サーバーを持たない完全な静的サイト**で、GitHub Pages 等に
そのまま公開できます。

## 特徴

- Python等のバックエンド不要。`index.html` / `style.css` / `app.js` の3ファイルのみ
- ブラウザから Semantic Scholar の API へ直接アクセス（CORS対応済み・APIキー不要で動作確認済み）
- 同姓同名の著者が見つかった場合は候補一覧から選択
- 共著関係のネットワーク構造から自動でグループ（色分け）を検出（ブラウザ内でラベル伝播法を実行）
- 取得した論文の一覧をリンク・分野（fields of study）付きで表示
- ノードをクリックするとその人の共著論文一覧と研究者プロフィールへのリンクを表示、つながり（線）をクリックすると2人の共著論文一覧を表示
- 同姓同名の別人の論文が誤って混ざっている場合など、論文・著者・つながりを個別に除外して手動修正可能（「除外をリセット」でいつでも元に戻せます。ブラウザを閉じると除外状態はリセットされます）

## なぜ Semantic Scholar のみか

当初は CiNii Research（国立情報学研究所）との選択式も検討しましたが、CiNii Research のAPI利用は公式に
アプリケーションID登録が必須とされており（無登録アクセスは予告なくブロックされる可能性がある）、登録の要否や
公開静的サイトでの妥当な運用方法を検討した結果、**登録不要が明確に許可されている Semantic Scholar のみ**を
採用しています。Semantic Scholar の利用規約は匿名アクセスを明示的に許可しており、必須要件である帰属表示も
本ページのフッターで満たしています。

トレードオフとして、Semantic Scholar は英語論文・国際会議中心のデータベースのため、日本語のみの学会発表・
紀要論文は収録が薄いことがあります。検索後に表示される「取得した論文一覧」で、実際に何がヒットしたかを
確認できます。

## ローカルで試す

静的ファイルなので、任意の簡易HTTPサーバーで確認できます。

```bash
cd coauthor-network-web
python3 -m http.server 8000
```

`http://127.0.0.1:8000` を開いてください（`file://` で直接開くとブラウザによっては `fetch` がブロックされる
ことがあるため、簡易サーバー経由を推奨します）。

## GitHub Pages への公開

1. このディレクトリの内容をGitHubリポジトリにpush
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、対象ブランチのルート（`/`）に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 図の見方

- 円の大きさ：中心著者との共著論文数
- 線の太さ：2名の著者間の共著論文数
- 色：共著ネットワークの構造から自動検出したグループ（ラベル伝播法によるコミュニティ検出）。
  所属研究室などの人手による分類ではありません
- 表示件数が多くなりすぎないよう、共著論文数が多い上位の共著者のみを図に表示しています
- ネットワークは「中心の著者と直接共著した人」までの1段階のみで、共著者のそのまた共著者へは広げません

## 構成

```

app.js       Semantic Scholar 連携・共著グラフ集計・コミュニティ検出・フォースレイアウト描画
```
