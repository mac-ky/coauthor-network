# 共著者ネットワーク検索（静的サイト版）

著者名を入力すると学術データベース（[CiNii Research](https://cir.nii.ac.jp/) または
[Semantic Scholar](https://www.semanticscholar.org/)）から論文情報を取得し、共著関係をインタラクティブな
ネットワーク図として可視化するWebアプリです。**サーバーを持たない完全な静的サイト**で、GitHub Pages 等に
そのまま公開できます。

## 特徴

- Python等のバックエンド不要。`index.html` / `style.css` / `app.js` の3ファイルのみ
- ブラウザから各データベースのAPIへ直接アクセス（両APIともCORS対応済みで動作確認済み）
- データソースを **CiNii Research**（日本語の学会発表・紀要中心）と **Semantic Scholar**（英語論文・国際会議中心）で切り替え可能
- 同姓同名の著者が見つかった場合は候補一覧から選択
- 共著関係のネットワーク構造から自動でグループ（色分け）を検出（ブラウザ内でラベル伝播法を実行）

## ローカルで試す

静的ファイルなので、任意の簡易HTTPサーバーで確認できます。

```bash
cd coauthor-network-web
python3 -m http.server 8000
```

`http://127.0.0.1:8000` を開いてください（`file://` で直接開くとブラウザによっては `fetch` がブロックされる
ことがあるため、簡易サーバー経由を推奨します）。

## GitHub Pages への公開

1. このディレクトリの内容をGitHubリポジトリにpush
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、対象ブランチのルート（`/`）に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## データソースについて

| | CiNii Research | Semantic Scholar |
|---|---|---|
| 提供元 | 国立情報学研究所（NII） | Allen Institute for AI |
| 得意分野 | 日本語の学会発表・紀要・機関リポジトリ | 英語論文・国際会議 |
| 著者の同定 | 研究者ID（CRID）で検索・disambiguation可能。ただし論文中の共著者リストは氏名文字列のみ | 著者ID（authorId）で一意に識別 |
| APIキー | 不要（匿名アクセス可） | 不要（匿名アクセス可、ただしレート制限が厳しめ） |

いずれも無料の公式APIです。CiNii Research は共著者ごとの一意なIDまでは提供していないため、表記ゆれのある
同姓同名者が別人として分かれる可能性がある点にご注意ください。

## 図の見方

- 円の大きさ：中心著者との共著論文数
- 線の太さ：2名の著者間の共著論文数
- 色：共著ネットワークの構造から自動検出したグループ（ラベル伝播法によるコミュニティ検出）。
  所属研究室などの人手による分類ではありません
- 表示件数が多くなりすぎないよう、共著論文数が多い上位の共著者のみを図に表示しています

## 構成

```
index.html   ページ本体・検索UI
style.css    デザイントークン・レイアウト
app.js       データソースアダプタ（CiNii Research / Semantic Scholar）
             共著グラフ集計・コミュニティ検出・フォースレイアウト描画
```
